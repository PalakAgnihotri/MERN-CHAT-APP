💬 MERN Chat Application

A real-time chat application built using the MERN stack with Socket.io for instant messaging.
Users can register, login, search other users, create one-to-one and group chats, and exchange messages in real time with typing indicators and notifications.

🚀 Features

🔐 User Authentication (Login & Signup)

👥 One-to-One Chat

👨‍👩‍👧 Group Chat

⚡ Real-time Messaging using Socket.io

✍️ Typing Indicator

🔔 Message Notifications

📸 Profile Picture Upload (Cloudinary)

🔍 Search Users

📱 Responsive UI (Chakra UI)
🛠️ Tech Stack

Frontend:

React.js

Chakra UI

Axios

Socket.io-client

Backend:

Node.js

Express.js

MongoDB (Mongoose)

JWT Authentication

Socket.io
